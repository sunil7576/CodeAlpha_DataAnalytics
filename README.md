# CodeAlpha Data Analytics Internship

## Overview

This repository contains the projects completed during the CodeAlpha Data Analytics Internship. The tasks focus on data collection, analysis, visualization, and sentiment analysis using Python and Power BI.

---

## Internship Tasks

### Task 1: Web Scraping

#### Objective
Extract data from a website and create a structured dataset.

#### Tools Used
- Python
- Requests
- BeautifulSoup
- Pandas

#### Output
- books_data.csv

---

### Task 2: Exploratory Data Analysis (EDA)

#### Objective
Explore and analyze datasets to identify trends, patterns, and insights.

#### Tools Used
- Power BI
- CSV Dataset

#### Key Activities
- Data Cleaning
- Missing Value Handling
- Data Exploration
- Statistical Analysis
- Insight Generation

---

### Task 3: Data Visualization

#### Objective
Transform raw data into meaningful visual insights using dashboards.

#### Tools Used
- Power BI

#### Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Sales by Category
- Profit by Region
- Monthly Sales Trend
- Customer Analysis
- Interactive Filters

### Task 4: Sentiment Analysis

#### Objective
Analyze customer reviews and classify sentiments.

#### Tools Used
- Python

- Matplotlib
